Password Strength Checker

A beginner C++ project built as part of my cybersecurity learning journey.

About
This program analyzes a password and tells you how strong it is based on multiple security criteria.

How It Works
The program checks 4 conditions:
- Contains numbers (0-9)
- Contains capital letters (A-Z)
- Contains small letters (a-z)
- Contains special symbols (!@#$%&)

It also penalizes weak patterns:
- Sequential numbers (123, 456, 789)

Results
- 4 conditions met  : Strong Password
- 3 conditions met  : Medium Password
- 2 conditions met  : Lower Medium Password
- 1 or less         : Weak Password
